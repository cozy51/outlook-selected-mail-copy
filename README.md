# Outlook 選択メールコピー

Outlook Webで開いているメッセージの本文を1件だけ取得して、確認後にクリップボードへコピーするChrome拡張機能（Manifest V3）。

## インストール
1. ZIPを解凍する。
2. Chromeで `chrome://extensions/` を開く。
3. 「デベロッパーモード」をオンにする。
4. 「パッケージ化されていない拡張機能を読み込む」から、manifest.jsonのあるフォルダを選択。
5. Outlook Webでメールを1件開き、拡張機能アイコンを押す。
6. ポップアップを開いた時点で自動的にコピーされます（ボタンが緑の「✓ コピー済み」になります）。必要なら「この1件をコピー」で再コピーできます。

## 制約と安全性
- 対象サイトは Outlook Web (`outlook.office.com`, `outlook.office365.com`, `outlook.live.com`, `outlook.cloud.microsoft`)。Windowsデスクトップアプリ版には非対応。
- OutlookのHTML構造は組織・バージョン・表示方式で異なるため、本文が検出されない場合があります。その場合は誤コピー防止のため停止します。
- スレッド中の複数メールの本文を検出した場合も停止します。
- 件名・差出人・日時は取得できた項目だけをコピーします。取得できない項目の見出しや代替文言は表示しません。
- 「件名・差出人・日時を含める」のチェック状態はChrome内に保存され、次回開いたときにも維持されます。
- 添付ファイルはコピーしません。本文内の画像やHTML装飾もコピーせず、プレーンテキストのみです。
- ネットワーク送信・外部サーバー保存・常駐監視を行いません。

## v1.1.1 アイコン更新
- 青い封筒＋コピーのアイコンを追加（16/32/48/128 px）。
- `manifest.json` の `icons` と `action.default_icon` を設定。
- 既存フォルダを上書きした後、`chrome://extensions/` で再読み込みしてください。

## v1.2.0 自動コピー
- ポップアップを開いてメールを取得できた時点で、ボタンを押さなくてもクリップボードへコピーします。
- コピー済みのときはボタンが緑の「✓ コピー済み」になり、プレビュー枠も緑になります。
- 「件名・差出人・日時を含める」を切り替えた場合は、切り替え後の内容で自動的にコピーし直します。
- 自動コピーに失敗した場合はステータスに理由を表示し、ボタンは通常表示のままです。

## v1.3.0 対象の選択（初期値：最新メールのみ）
- ポップアップ上部の「対象」で、コピーする範囲を選べます。選択はChrome内に保存され、次回も維持されます。
  - **最新メールのみ（初期値）**：スレッドで複数のメールが展開されていても、日時が最も新しい1件を選びます。また、返信・転送で本文末尾に付く過去のやり取り（「-----Original Message-----」「差出人: … 送信日時: …」「From: … Sent: …」「On … wrote:」など）を除いてコピーします。
  - **開いているメール（そのまま）**：従来どおり、展開されている1件の本文を引用部分も含めてそのままコピーします。複数展開されている場合は停止します。
- 日時を読み取れず最新の1件を判定できない場合は、誤コピー防止のため停止します。

## v1.4.0 遡る件数の指定
- 「対象」のドロップダウンで、返信・転送の引用に含まれる過去のやり取りを何件前まで含めるかを選べます。選択はChrome内に保存されます。
  - 最新メールのみ（初期値）／1件前まで〜4件前まで遡る／すべて（開いているメールをそのまま）
- 過去のやり取りの件数は、本文中の引用の区切り（「差出人: … 送信日時: …」「From: … Sent: …」「-----Original Message-----」「On … wrote:」など）で数えます。指定より引用が少ない場合は、ある分をすべて含めます。
- v1.3.0 で保存した設定（最新メールのみ／開いているメール）はそのまま引き継がれます。

## v1.5.0 差出人・日時の取得精度を改善
- 差出人の判定に [cozy51/OLM-Achiver](https://github.com/cozy51/OLM-Achiver) の方式を移植しました（`scan-sender.js`・`sender.js`）。
  - Outlookの差出人欄（`MSG_…_FROM`）、選択中のメール一覧の行、メールヘッダー（「宛先:」行より上・プロフィールカードの対象）から候補を集めて採点し、確信できる1件だけを差出人として使います。
  - 「赤星 善弘（Akahoshi,Y.）」のような表示名をそのまま使い、メールアドレスが読める場合は `<アドレス>` を併記します。
  - スレッドで複数のメールが展開されている場合は、コピー対象に選んだ1件の差出人を優先します。
- 日時は「日付＋時刻」として読める値だけを採用し、`2026-11-09 (月) 10:23` の形式に揃えます（`mail-date.js`）。添付ファイル名など日付を含むだけの文字列を日時として表示する不具合を修正しました。
- 件名は見出し要素が見つからない場合にタブのタイトルから補います。
