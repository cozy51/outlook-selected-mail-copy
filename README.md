# Outlook 選択メールコピー

Outlook Webで開いているメッセージの本文を1件だけ取得して、確認後にクリップボードへコピーするChrome拡張機能（Manifest V3）。

## インストール
1. ZIPを解凍する。
2. Chromeで `chrome://extensions/` を開く。
3. 「デベロッパーモード」をオンにする。
4. 「パッケージ化されていない拡張機能を読み込む」から、manifest.jsonのあるフォルダを選択。
5. Outlook Webでメールを1件開き、拡張機能アイコンを押す。
6. 内容を確認して「この1件をコピー」を押す。

## 制約と安全性
- 対象サイトは Outlook Web (`outlook.office.com`, `outlook.office365.com`, `outlook.live.com`, `outlook.cloud.microsoft`)。Windowsデスクトップアプリ版には非対応。
- OutlookのHTML構造は組織・バージョン・表示方式で異なるため、本文が検出されない場合があります。その場合は誤コピー防止のため停止します。
- スレッド中の複数メールの本文を検出した場合も停止します。
- 件名・差出人・日時は取得できた項目だけをコピーします。取得できない項目の見出しや代替文言は表示しません。
- 「件名・差出人・日時を含める」のチェック状態はChrome内に保存され、次回開いたときにも維持されます。
- 添付ファイルはコピーしません。本文内の画像やHTML装飾もコピーせず、プレーンテキストのみです。
- ネットワーク送信・外部サーバー保存・常駐監視を行いません。
